A REST API for tracking specifically coding sessions, I used spring boot and spring data JPA to develop the backend service, controller and repository layer. For the database I used postgres.

Features included through the backend endpoints
- log
- update
- view table
- delete

Run it by cloning the repo
Set up a PostgreSQL database and update application.properties with your credentials
Run the app via IntelliJ
Test endpoints at http://localhost:8080
